# Инструкция для агента

Это анализатор фотографий `kemerovo-city-photo`, локальная папка `int_map`.
Веб-сервис находится отдельно в `../kemerovo-photo-map`, переносимый просмотрщик —
в `../kemerovo-photo-map-portable`. Не копировать их код сюда.
Перед работой прочитать README и проверить Git; сохранять пользовательские изменения.

- Оригиналы не изменять и не переименовывать. Фото, миниатюры, GPS, EXIF, ответы
  модели, SQLite, результаты и пароли не отправлять в облачные API, vision агента
  или GitHub. Реальные изображения обрабатывает только локальная Ollama.
- `work`, `output`, `comparison_*`, `maps` и местные материалы могут содержать
  единственные экземпляры результатов. Исключение из Git не означает ненужность.
- Перед записью в рабочую базу проверить активный анализатор и веб-очередь.
  Не запускать параллельные GPU-проходы. В тестах использовать временные каталоги.
- Модель, ресурсы и настройки не подменять скрыто. Thinking-веса автоматически
  не удалять. Не трогать FanControl, вентиляторы и системные настройки.
- Один workspace связан с одним входным корнем. Несколько папок для сайта добавляет
  его `import_folders.py`. Не менять `input_root` вручную.
- Null не заменять нулём, ошибку не выдавать за успех. Готовые результаты
  и прошедшие тесты не доказывают качество оценок модели.

Ресурсы хранятся только в `city_photo/resources`. Пути YAML относительны его файлу.
`run_background.py`, `config.full.yaml` и скрипты в корне используются соседним сайтом.
При их изменении проверять совместимость с ним.

После установки `.[test]`, из корня:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m pip wheel . --no-deps --wheel-dir dist
```

Полный архив ради проверки кода не запускать. Перед публикацией проверять состав Git:
только код, ресурсы, синтетические примеры и документация.
Коммиты и push выполнять по запросу пользователя.
